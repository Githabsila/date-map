# Куда сходить вдвоём

Карта мест для свидания. Пишешь, чего хочется («мясное, но недорого», «купить фигурку Hello Kitty»),
выбираешь город, тип места и бюджет. Сайт ищет в **своей бесплатной базе OpenStreetMap** и,
если есть ключи, в **2ГИС, Яндекс Картах и Google Maps**, склеивает одинаковые места,
отсеивает слишком дорогие и показывает всё на одной карте со ссылками на каждую из карт.

## Запуск

Дважды кликни `run.bat`. Он сам создаст окружение, поставит зависимости и откроет http://localhost:8000.

Вручную:

```bash
python -m venv .venv
.venv\Scripts\python -m pip install -r requirements.txt
copy .env.example .env
.venv\Scripts\python -m uvicorn app.main:app --port 8000
```

## Бесплатная база мест (OpenStreetMap)

Главный источник — своя база из открытых данных OpenStreetMap. Бесплатно навсегда, без ключей и лимитов,
можно использовать и в коммерческом проекте (нужно указывать «© OpenStreetMap», на карте это уже есть).

```bash
sh scripts/download_russia.sh      # скачать всю Россию (~4 ГБ) и собрать data/places.db
```

Или отдельные регионы с https://download.geofabrik.de:
`python scripts/build_osm_db.py data/raw/файл.osm.pbf [ещё файлы]`.
Обновлять раз в 1–3 месяца: данные OpenStreetMap постоянно дополняются.

В OpenStreetMap нет рейтингов и среднего чека, поэтому у каждого места есть ссылка «Отзывы в Яндексе».
Рейтинги и чек добавляются, если подключить 2ГИС.

Без базы и без ключей сайт работает в **демо-режиме**: показывает выдуманные места, чтобы можно было посмотреть интерфейс.
Как только в `.env` появится хотя бы один ключ карт, демо выключается.

Тесты: `.venv\Scripts\python -m pytest`

## Где взять ключи

Ключи вставляются в файл `.env` (не в код и не в чат). После изменения `.env` перезапусти сервер.
Условия и лимиты у сервисов меняются, поэтому перед запуском для реальных пользователей сверься с их страницами.

### 1. Яндекс: «API Поиска по организациям» → `YANDEX_API_KEY`
1. Зайди в Кабинет разработчика: https://developer.tech.yandex.ru (нужен Яндекс ID).
2. «Подключить API» → **«API Поиска по организациям»** (не путай с «JavaScript API и HTTP Геокодер»).
3. Заполни анкету и получи ключ. Ключ начинает работать примерно через 15 минут.
4. Бесплатный тариф даёт ограниченное число запросов в сутки и только для некоммерческого использования.

**Важно:** по правилам Яндекса результаты этого API нужно показывать на карте Яндекса.
Здесь для простоты стоит OpenStreetMap. Перед коммерческим запуском либо купи лицензию Яндекса
и переведи карту на Яндекс JS API, либо оставь только 2ГИС.

Этот API не отдаёт рейтинг и средний чек, только название, адрес, рубрику и телефон.

### 2. 2ГИС: Places API → `TWOGIS_API_KEY`
1. Зарегистрируйся в Платформе 2ГИС: https://platform.2gis.ru
2. Создай ключ: сначала выдают **демо-ключ** с ограничениями по сроку и числу запросов.
3. Для постоянной работы нужен коммерческий ключ (заявка в 2ГИС, платно).

Это самый полезный источник для России: есть рейтинг, число отзывов и часто средний чек.

### 3. Google: Places API (New) → `GOOGLE_API_KEY`
1. https://console.cloud.google.com → создай проект.
2. «APIs & Services» → «Library» → включи **Places API (New)**.
3. «Credentials» → «Create credentials» → «API key». Ограничь ключ только этим API.
4. Нужно привязать платёжный аккаунт с картой. Есть бесплатный месячный лимит, дальше платно.
   Российские карты Google не принимает.

Даёт рейтинг и уровень цен. В России данных у Google меньше, чем у 2ГИС и Яндекса.

### 4. (Необязательно) Claude → `ANTHROPIC_API_KEY`
Нужен, чтобы сайт понимал любые свободные запросы, а не только ключевые слова.
https://console.anthropic.com → «API Keys» → «Create Key». Оплата по факту использования.
Без ключа работает встроенный разбор по ключевым словам. Он понимает еду, развлечения, бюджет и «купить …».

Модель задаётся в `CLAUDE_MODEL`. По умолчанию стоит `claude-opus-5-5` с минимальным уровнем рассуждений (effort `low`).
Если ИИ-модель откажется отвечать по соображениям безопасности, запрос автоматически
перейдёт на другую модель (параметр `fallbacks`).

## С чего начать
Хватит базы OpenStreetMap: сайт уже настоящий и бесплатный. Ключ 2ГИС добавит рейтинги и средний чек.

## Сколько запросов тратится и защита лимитов
Один поиск = до 3 поисковых фраз × число платных карт. База OpenStreetMap лимит не тратит.
Одинаковые запросы 10 минут берутся из кэша.

- `SEARCHES_PER_IP` / `SEARCH_WINDOW_S` — не больше 15 поисков с одного адреса за 10 минут.
- `DAILY_PROVIDER_CALLS` — сколько запросов к платным картам в сутки (по умолчанию 30 ≈ 900 в месяц,
  под демо-ключ 2ГИС). Когда закончились, сайт продолжает искать по OpenStreetMap.

## Рабочий сайт на VPS

Нужен сервер с Ubuntu 22.04/24.04 (1 ядро, 1–2 ГБ памяти) и SSH-ключ, добавленный при создании сервера.

```bash
sh deploy/deploy.sh <IP сервера> [домен]
```

Скрипт ставит Docker, открывает только порты 22/80/443, копирует сайт, базу мест и `.env`,
запускает сайт с автоперезапуском и HTTPS (Caddy). Без домена адрес будет `https://<ip-через-дефисы>.sslip.io`.
Обновление сайта — та же команда.

## Бесплатно на Render

`render.yaml` уже настроен: на render.com → New → Blueprint → репозиторий с проектом.
Ключи вводятся в панели Render. База мест не помещается в GitHub, поэтому положи `places.db.gz`
в GitHub Releases и укажи ссылку в `PLACES_DB_URL` — база скачается при сборке.
Бесплатный сервер засыпает без посетителей; чтобы не засыпал, поставь бесплатную проверку
на cron-job.org (адрес `https://<сайт>/healthz` каждые 10 минут).

## Устройство проекта

```
app/
  main.py          сервер: /api/search, /api/status и раздача страницы
  parser.py        разбор запроса по ключевым словам (без ИИ)
  llm.py           разбор запроса через Claude (если есть ключ)
  merge.py         склейка одинаковых мест из разных карт, бюджет, сортировка
  limits.py        защита лимитов: поиски с одного IP и дневной бюджет платных карт
  cities.py        координаты городов: список, своя база, геокодер OpenStreetMap
  providers/       osm.py (своя база), twogis.py, yandex.py, google.py, demo.py
scripts/           build_osm_db.py, download_russia.sh, fetch_db.py
deploy/            deploy.sh, setup-server.sh, Caddyfile (+ Dockerfile, docker-compose.yml, render.yaml)
static/            страница: index.html, app.js, style.css (карта Leaflet + OpenStreetMap)
tests/             тесты
```
